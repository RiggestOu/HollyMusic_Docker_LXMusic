### 关键架构迁移

| 原 LX Music | 新 HollyMudic |
|------------|--------------|
| src/main/modules/userApi/ | src/main/modules/source/ |
| USER_API_RENDERER_EVENT_NAME | source_* |
| electron-store | electron-store (保持) |
| 无 Docker | Docker + Alpine |

### 技术要点
- 音源脚本使用 gzip + base64 压缩存储
- BrowserWindow 沙箱隔离执行自定义音源
- IPC 请求队列 + 20秒超时机制
- 持久化配置存储在 /data/config Volume
- 使用 electron-vite 构建工具
